# 🕷️ スパイダーソリティア（効果音付き）

ブラウザだけで遊べる、効果音付きのスパイダーソリティアです。
ビルド不要・外部ライブラリ不要。`index.html` を開くだけで動きます。

## 遊び方

1. `index.html` をブラウザで開く
2. カード（またはその上に続く同スートの連番）をクリックして選択
3. 移動先の列をクリックして移動
4. 同じスートで **K→A** の13枚を並べると一組完成。**8組すべて**完成でクリア！
5. 右下の山札をクリックすると、全列に1枚ずつ配られます（空列があると配れません）

## 機能

- **スート数の選択**：1種（やさしい）／2種（ふつう）／4種（むずかしい）
- **効果音**：Web Audio API でリアルタイム生成（音声ファイル不要）
  - カードを選ぶ／置く／配る／完成／クリアのファンファーレ／無効操作 など
  - 右上の「🔊 音」ボタンで ON / OFF 切り替え
- **一手戻す（Undo）**
- **ヒント**：おすすめの手を点滅表示
- **得点・手数・完成数・残り山札**の表示
- スマホ・タブレット対応のレスポンシブ表示

## ファイル構成

- `index.html` … 画面構成
- `style.css` … スタイル
- `game.js` … ゲームロジックと効果音生成

## 技術

- Vanilla JavaScript（フレームワークなし）
- 効果音はオシレーターによる合成音（外部アセット不要）
